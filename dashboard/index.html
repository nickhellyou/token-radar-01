Which pre-token protocol is worth farming next?

200 protocols that record no token, ranked by what a token would be worth if the protocol launched one today. The value is fitted from the 128 protocols whose token already trades, not from a TVL table and not from a list of names.

Implied values are this radar’s claim, never make.fun’s. A record of no token is not proof there is none; nothing here says if or when a token launches.

How the value is built

value if launches = exp(a + b · ln(forward TVL)) × category premium
implied value = value if launches × launch odds

Forward TVL carries TVL one quarter on its 7-day change, capped at ±20%. Launch odds rise with age tracked and no token, from 0.20 toward 0.75. The P10–P90 band comes from the fit’s own residuals.

Does it hold on tokens it never saw?

The curve is re-fitted on two of every three trading protocols and scored on the held-out third. Crypto market caps are noisy, so the band is wide and the board says so instead of pretending precision.
